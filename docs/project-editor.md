# Редактирование проектов

На странице любого проекта нажмите «Редактировать проект» / “Edit project”. Вход использует тот же пароль автора, что и архив; пароль хранится только в серверной конфигурации.

- Перетаскивайте блоки за ручку или перемещайте их кнопками вверх/вниз. На телефоне используйте кнопки.
- Нажмите «Сохранить порядок». «Отменить изменения» возвращает последнее сохранённое расположение.
- «Загрузить фотографии» принимает PNG, JPG, WebP и GIF до 8 МБ каждый. Можно выбрать несколько файлов. Загрузка также сохраняет текущий порядок.
- Крестик убирает блок из галереи после сохранения; исходный файл остаётся в хранилище.
- Если проект изменён в другой вкладке, редактор сообщает о конфликте вместо перезаписи чужих изменений.
- У PENTA-Q первая фотография становится обложкой в списке проектов. До загрузки отображается название проекта.

Текущие изменения доступны на http://localhost:3000. Галереи сохраняются в локальной D1, файлы — в локальной R2. Для переноса на опубликованный сайт потребуется отдельная публикация и перенос локально загруженных файлов/данных.

Проверка: `node scripts/check-project-gallery.mjs` (при работающем сервере на порту 3000). Проверяет вход, защиту записи, загрузку, чтение файлов, сохранение порядка и конфликты; возвращает исходный состав галереи PENTA-Q.
