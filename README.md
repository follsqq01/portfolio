## Редактирование архива

Откройте `/archive` → «Редактировать архив». Пароль локального режима автора хранится в `.dev.vars` в `ADMIN_PASSWORD`; файл исключён из исходников. Сеанс в защищённой HttpOnly cookie действует 7 дней. После входа доступны добавление, редактирование и удаление карточек, загрузка изображения и создание категории. Перевод на английский необязателен. Сохранение сразу меняет общий архив; открытые страницы проверяют изменения каждые 10 секунд и при возвращении во вкладку.

Архив хранится в D1 (`DB`), загруженные изображения — в R2 (`BUCKET`). При первом обращении база получает исходную коллекцию из `data/archive.json`. После этого изменения этого JSON не заменяют данные базы. Пустая коллекция остаётся пустой. Одновременные изменения из разных вкладок защищены проверкой версии: устаревшее сохранение отклоняется, содержимое формы сохраняется.

Для нового локального окружения: скопируйте `.dev.vars.example` в `.dev.vars`, задайте длинный пароль, выполните `npm run db:migrate:local`, затем `npm run dev -- --port 4174`. Локальные данные находятся в `.wrangler/state`; не удаляйте этот каталог, если хотите сохранить загрузки и правки.

Проверка API: `npm run check:archive` при запущенном локальном сервере. Проверка создаёт и удаляет свою тестовую карточку, сохраняя исходную коллекцию.

Для публикации необходимо подключить D1 и R2 к тому же сайту, применить миграции из `drizzle` и задать серверный секрет `ADMIN_PASSWORD`. Локальная база не является опубликованной базой; локальные изменения не переносятся в интернет автоматически. При первом развёртывании нужно отдельно перенести актуальную коллекцию и загруженные файлы. Все последующие сохранения на опубликованном сайте доступны его посетителям без повторной сборки.
